## Тема оформления

Название темы — «Горный грейд». Контракт — восемь токенов.

| Токен | Значение | Назначение |
|---|---|---|
| `--bg` | `#131417` | Фон |
| `--surface` | `#3a2a28` | Панели и плашки |
| `--text` | `#ece8e1` | Основной текст |
| `--text-muted` | `#b7b0a3` | Вторичный текст, светлые плашки |
| `--accent` | `#a04a4e` | Единственный акцент: заголовки, линии, плашки |
| `--accent-dim` | `#b9696c` | Акцент для мелких элементов и акцентного текста |
| `--font-head` | Dela Gothic One | Заголовки |
| `--font-body` | Golos Text | Текст |

**Два токена изменены против исходной версии бренда — оба по красным линиям пака, оба требуют вашего подтверждения.**

1. `--accent-dim` был `#b25457`. Роль этого токена — «акцент для мелких элементов, если основной не проходит по контрасту», а `#b25457` даёт 3,77 при пороге 4,5 и роль не выполняет. Заменён на `#b9696c` — тот же тон, светлее на 11%, контраст 4,65. Если хотите вернуть `#b25457` — верните, но тогда акцентным цветом нельзя набирать текст мельче крупного кегля вообще.
2. `--font-body` был Manrope. Manrope в списке шрифтов, которые не используются для кириллицы: кириллический набор в нём сделан формально. Заменён на **Golos Text** (альтернатива — IBM Plex Sans). Замена затрагивает все существующие макеты, поэтому решение стоит принять осознанно, а не по ходу.

### Контраст, посчитанный по WCAG 2.2

Проверено 05.08.2026. Порог бинарный: обычный текст — 4,5:1, крупный (от 24 CSS px, или 19 px полужирным) — 3:1.

| Пара | Контраст | Обычный | Крупный |
|---|---|---|---|
| `--text` на `--bg` | 15,08 | ✅ | ✅ |
| `--text-muted` на `--bg` | 8,55 | ✅ | ✅ |
| `--accent` на `--bg` | 3,14 | ❌ | ✅ |
| `--accent-dim` `#b9696c` на `--bg` | 4,65 | ✅ | ✅ |
| `--text` на `--surface` | 11,15 | ✅ | ✅ |
| `--text-muted` на `--surface` | 6,33 | ✅ | ✅ |
| `--accent` на `--surface` | 2,32 | ❌ | ❌ |
| `--accent-dim` на `--surface` | 3,44 | ❌ | ✅ |
| `--text` на плашке `--accent` | 4,80 | ✅ | ✅ |
| `--bg` на плашке `--text-muted` | 8,55 | ✅ | ✅ |
| `--surface` на `--bg` (не текстовая пара) | 1,35 | — | — |

**Правила, которые из этого следуют**

1. **`--accent` текстом не набирается** — только крупные заголовки, линии, плашки. Мелкий и обычный текст акцентом — `--accent-dim`.
2. **На панелях `--surface` акцент почти не работает:** основной не проходит вовсе, осветлённый годится только для крупного. Практически: на панелях текст — `--text` или `--text-muted`.
3. **Панели визуально не отделяются от фона** (1,35). Нужна рамка, тень или более светлый `--surface`. [ПРОБЕЛ: решение не принято]

### Технические ограничения собственного бота

Выстраданы на проекте TRAVA, менять без причины не стоит.

- Deeplink — **только латиницей**, вида `start=plan`, `start=shema`, `start=shop`, `start=zayavka`.
- Кириллица — только в триггер-словах, которые пишет пользователь.
- **Триггер-слова без буквы «ё»** — иначе совпадение в комментариях ломается. Это правило напрямую определяет список слов в `offer.md`.
- Одно слово — один магнит, одна цель, один deeplink.
- Связи-кнопки: `condition = текст кнопки`, `comparision_method = 0`, `show_as_button = False`.
- Текст кнопок — **не длиннее 64 байт UTF-8**.
- Файлы отдаются через `tg_send_document` по `file_id` при `save_webhook=1`.

### Сегментация базы

Поля еженедельной выгрузки: триггер-источник · сегмент (5 тегов) · статус: база / покупка / заявка на услугу / смета / договор.

## Производственные ограничения

### Время

- Блог: **8 часов в неделю, потолок жёсткий.** Поверх основной работы. Не влезает формат — упрощается формат, бюджет не расширяется.
- Услуга: **до 4 часов в неделю** личного времени (разбор брифа ≤30 мин, созвон ≤20 мин, архитектура, приёмка). Берутся из рабочего времени, не из блоговых восьми. Заявок больше, чем влезает, — очередь и честные сроки в смете, а не ночные часы.
- Восемь часов — часть позиционирования: это режим самой аудитории, и всё показанное должно быть повторимо в этом лимите.

### Стоимость форматов в часах

Замеры автора, не нормативы. Нужны для расчёта плана.

| Блок | Часы |
|---|---|
| Тексты: 4 поста в Telegram + карусель | 1,5–2 |
| Батч-съёмка (или добор со съёмок по основной работе) | 2–2,5 |
| Монтаж 3 коротких видео по ≤40 мин, CapCut | 2 |
| Публикации + «Цифры недели» + выгрузка базы | 0,7 |
| Блок длинного видео, раз в 2–4 недели | +3–4 |

Один лид-магнит — **один вечер**. Затянулся — режется объём, а не срок. Исключение: флагману ЗАЩИТА разрешено два вечера, потому что обязателен фактчек норм и цифр.

### Чем снимается и монтируется

- Съёмка: телефон. Кадр, экран, стол — темы только те, что снимаются здесь и сейчас, без погоды и реквизита.
- Аэросъёмка не используется.
- Монтаж коротких видео: CapCut, лимит 40 минут на ролик. Превысил дважды подряд — упрощается шаблон.
- «Кино» в DaVinci — не чаще двух раз в месяц и только из уже отснятого.
- Съёмка оппортунистическая: каждый выезд по основной работе даёт 1–2 минуты материала.
- Сторис снимаются с телефона без сценариев — это сырьё с батчей.

### Иерархия приоритетов при конфликте за время

1. Обязательства по основной работе: запуск аккаунта компании и съёмки TRAVA.
2. Обязательства по подписанным договорам услуги (исполняет команда, автор — архитектура и приёмка).
3. Команда: платформа, партнёрка, CRM, онбординг, загрузка разработчиков.
4. Личный блог и сборка цифровых товаров.

Порядок жёсткий, с одной оговоркой: **блоговые 8 часов не отдаются услуге добровольно.** Блог и есть канал заявок; резать его ради исполнения — глушить собственный двигатель. Пропущенная неделя честно объявляется в «Цифрах».
