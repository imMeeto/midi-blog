# MIDI FILM

Плагин личного бренда Дмитрия Турбабина: контекст и 45 навыков content-producer. Всего 46 навыков.

## Установка в Claude

- **claude.ai, приложение для компьютера и телефона:** Customize → Plugins → Add → Add marketplace → `imMeeto/midi-blog`, затем включить MIDI FILM. Другой путь: Add → Upload plugin и загрузить zip этой папки. Плагин, добавленный в аккаунт, доступен в чатах на всех устройствах и в Claude Code под тем же аккаунтом (`/reload-plugins`).
- **Claude Code отдельно:** `/plugin marketplace add imMeeto/midi-blog`, затем `/plugin install midifilm@midifilm`.

## Использование

Подключите плагин MIDI FILM в своём аккаунте. Если версия 1.0.0 уже установлена, обновите её до 1.1.0 через управление плагинами. В новом чате выберите MIDI FILM и назовите задачу или нужный навык.

- «Используй cp-script-short: сценарий на минуту от моего лица».
- «Используй cp-content-plan: контент-план с учётом моих 8 часов в неделю».
- «Используй cp-voice, затем cp-humanizer: перепиши этот текст моим голосом».
- «Используй content-producer: помоги собрать запуск блога».
- «Подключи мой контекст через midifilm-context».

В Codex доступны явные вызовы `$cp-script-short`, `$cp-content-plan`, `$content-producer` и остальных навыков, когда новая версия установлена. [Полный каталог](context/11-skill-catalog.md).

## Содержимое и обновление

Включены все 45 навыков из midi-skills, их дополнительные материалы, 10 методических справочников и полные восемь документов бренда. Профиль MIDI FILM выбирается по умолчанию при прямом вызове каждого навыка. Другой клиентский бренд использует собственный профиль. Для чтения контекста доступ к исходному репозиторию не требуется.

Сведения о бренде описывают состояние на 05.08.2026, offer.md — на 08.10.2026; версия 1.1.0 собрана 12.10.2026, 1.1.1 (обновлён offer.md) — 14.10.2026. Даты сборки и импорта не являются датами перепроверки статистики, права, API и цен сервисов. Изменения локальных файлов сами не обновляют установленный плагин. Для следующей версии попросите обновить тот же плагин через Plugin Creator.

Навыки не подключают автоматически социальные сети и внешние сервисы. Работа с ними зависит от инструментов, доступных в конкретном чате. Подключение плагина также не открывает историю других чатов.

Иконка — служебная монограмма в базовых цветах бренда. Статус предложенных замен шрифтов и мелкого акцента в исходных документах сохранён. [Происхождение методик и лицензия](context/12-import-provenance.md).
